# LoveHunt

Система охоты и отскоков (bounty hunting) на основе предметов, с интеграцией кланов и захватом территорий.

## Общая структура

LoveHunt предоставляет фреймворк для создания и выполнения охотничьих заданий («охоты»), которые выдаются игрокам через NPC-Охотника или через команды. Каждая охота — это предмет с метаданными (цель, награда, территория). Игроки держат охоту в инвентаре, выслеживают цель и приносят подтверждение охотнику, получая награду в денежном эквиваленте или предметами.

## Команды

| Команда | Алиасы | Описание | Пермишин |
|---|---|---|---|
| `/lovehunt` | `hunt`, `lh` | Открыть меню охоты и доступные задания | `lovehunt.use` |
| `/hunts` | — | Открыть полный список всех охот прямо | `lovehunt.use` |
| `/lovehuntadmin` | — | Администраторские команды | `lovehunt.admin` |

### Подкоманды `/lovehuntadmin`

- `reload` — перезагрузить config.yml и hunts.yml
- `create <id> <displayName>` — создать новую охоту
- `delete <id>` — удалить охоту
- `assign <player> <huntId>` — выдать охоту игроку
- `complete <player> <huntId>` — засчитать выполнение охоты
- `list` — показать все охоты

## Пермишины

| Пермишин | Описание | Default |
|---|---|---|
| `lovehunt.use` | Доступ к `/lovehunt` и меню охоты | true |
| `lovehunt.admin` | Доступ ко всем админ-командам | op |

## Конфигурация (`config.yml`)

### Основные параметры

```yaml
plugin:
  enabled: true
  debug: false

# NPC Охотника (Citizens)
npc:
  enabled: true
  id: -1                            # ID NPC, -1 = не привязан
  bind-distance: 6.0                # расстояние на правый клик

# Награды
rewards:
  enabled: true
  money:
    enabled: true                   # выплачивает через LoveCore.LoveEconomy
  items:
    enabled: true

# Плейсхолдеры
placeholders:
  enabled: true
  prefix: "lovehunt"

# База данных
database:
  file: "hunts.db"
  pool-size: 10
  connection-timeout: 30000
```

### Охоты (`hunts.yml`)

```yaml
hunts:
  wolf_hunt_easy:
    display-name: "<green>Волчья охота</green>"
    description: "Отследить и убить 5 волков в лесу"
    enabled: true
    weight: 10                      # вес при случайном выборе
    reward:
      money: 1000                   # выплачивается через LoveCore
      items:
        - "DIAMOND 2"
        - "EMERALD_ORE 1"
    territory:                      # где искать (опционально, требует LoveClaims)
      world: "world"
      claim-id: -1                  # -1 = любая территория, иначе конкретный клан
    difficulty: "EASY"              # EASY | MEDIUM | HARD
    duration-hours: 24              # время на выполнение охоты
    repeatable: true                # можно ли повторить охоту
```

## Интеграции

### LoveCore

Денежные награды выплачиваются через `LoveEconomy` — физические монеты в инвентарь игрока.

### LoveClans

Охоты могут быть привязаны к территориям кланов через LoveClaims. Клан получает награду коллективно, если хотя бы один член клана выполнил охоту.

### Citizens

NPC-Охотник, через которого выдаются и принимаются охоты (правый клик на NPC).

### PlaceholderAPI

Плейсхолдеры для отображения текущей охоты, прогресса выполнения, оставшегося времени.

## Механика охоты

1. **Получение охоты** → игрок берёт охоту у NPC-Охотника или через `/lovehunt`
2. **Отслеживание** → охота отображается в инвентаре как предмет с метаданными
3. **Выполнение** → игрок выполняет условие охоты (убить врагов, добыть материал, etc.)
4. **Завершение** → игрок возвращается к охотнику и подтверждает выполнение
5. **Награда** → игрок получает деньги, предметы, опыт и т.д.

## Зависимости

### Обязательные

- **Paper 1.21** — базовый Minecraft сервер

### Мягкие зависимости

- **LoveCore** — единая система валюты (LoveEconomy)
- **LoveClaims** — захват и привязка территорий к кланам
- **LoveClans** — информация о кланах
- **Citizens** — NPC-Охотник
- **PlaceholderAPI** — интеграция плейсхолдеров

## Установка и сборка

```bash
mvn package
```

Java 21, Paper 1.21. База данных: SQLite.

## Структура данных

- `hunts` — определения охот (ID, название, описание, награда)
- `hunt_progress` — активные охоты игроков (игрок, охота, прогресс, дата выдачи)
- `hunt_history` — история выполненных охот (для статистики и лидерборда)

## PlaceholderAPI

| Плейсхолдер | Описание |
|---|---|
| `%lovehunt_current_hunt%` | Текущая охота игрока |
| `%lovehunt_progress%` | Прогресс выполнения (в %) |
| `%lovehunt_total_completed%` | Всего охот выполнено |
| `%lovehunt_total_reward%` | Общая награда за охоты |
